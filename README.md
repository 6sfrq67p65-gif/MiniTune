# Yandex Music Mini Player для macOS 🎵

Неофициальный плавающий мини-плеер Яндекс Музыки для Mac. Показывает текущий трек и обложку, управляет воспроизведением и не теряется среди окон и вкладок браузера.

## Возможности

* 🪟 **Поверх всех окон** и на всех рабочих столах.
* 🎨 **Матовое стекло** в стиле macOS.
* 🔄 **Три вида:** вертикальный виджет, горизонтальная карточка и узкая полоса как у Dock. Размер каждого вида запоминается.
* 🔐 **Вход один раз:** плеер работает через сайт music.yandex.ru во встроенном окне. Логин и пароль приложение не видит и не хранит, сессию хранит системный WebKit.
* 🛡 **Устойчив к обновлениям сайта:** название трека, обложку и состояние плеера берёт из нескольких источников — Media Session API, интерфейса страницы и тега audio.

## Установка

Нужна macOS 14 (Sonoma) или новее.

1. Скачайте **`YandexMusicWidget.zip`** из [последнего релиза](../../releases/latest).
2. Распакуйте архив и перетащите приложение в папку **«Программы»**.
3. При первом запуске macOS предупредит, что разработчик не проверен. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз и нажмите **«Всё равно открыть»**.
4. Нажмите **«Открыть плеер»** и войдите в свой аккаунт Яндекса.

## Управление

| Кнопка | Действие |
|---|---|
| ⏮ ⏯ ⏭ | предыдущий трек, пауза/воспроизведение, следующий трек |
| «Открыть плеер» | окно сайта Яндекс Музыки: выбор музыки и вход |
| ▭ | сменить вид виджета |
| ⏻ | выйти из приложения |

Виджет перетаскивается за любое место, размер меняется за края. Если закрыть окно плеера крестиком, музыка продолжит играть.

## Сборка из исходников

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/6sfrq67p65-gif/YandexMusicWidget.git
   ```
2. Откройте `YandexMusicWidget.xcodeproj` в Xcode 16 или новее.
3. Нажмите `⌘R`.

## Как устроено

* **SwiftUI** — интерфейс виджета.
* **WKWebView** — скрытое окно с music.yandex.ru, в нём и играет музыка.
* **JavaScript** — раз в секунду виджет спрашивает у страницы, что сейчас играет, а кнопки виджета нажимают кнопки плеера на странице.
